# AssociationSelectors

关联选择器组件，基于 Ant Design Select 组件封装，主要用于处理有依赖关系的下拉选择场景。

#### Example

<Canvas of={AssociationSelectors.Primary} />

## Usage

```ts
import { AssociationSelectors } from "dinglan-ui";

const Example = () => {
  const [form] = Form.useForm();
  
  const onChangeProject = (value: string | number | boolean) => {
    console.log("选中的项目:", value);
    // 清空下级选项
    form.setFieldsValue({
      projectPhaseId: undefined,
      projectBatchId: undefined,
    });
    // 根据项目获取期数选项
    fetchProjectPhases(value);
  };

  return (
    <Form form={form}>
      <Form.Item label="项目" name="projectId">
        <AssociationSelectors
          options={[
            { name: "鹿溪源", code: "project_1" },
            { name: "龙栖海岸", code: "project_2" },
          ]}
          onChange={onChangeProject}
          allowClear={true}
          placeholder="请选择项目"
        />
      </Form.Item>
    </Form>
  );
};

export default Example;
```

#### Arguments

- **options** _`Array<{name: string, code: string | number | boolean}>`_ - 选项数据数组，每个选项包含显示名称(name)和值(code)。
- **onChange** _`(value: string | number | boolean) => void`_ - 当选择项改变时调用的回调函数，接收选中的值作为参数。
- **allowClear** _`boolean`_ - 是否显示清除按钮，允许清空选择。
- **placeholder** _`string`_ - 输入框占位文本。
- **suffixIcon** _`React.ReactNode`_ - 自定义的选择框后缀图标。
- **disabled** _`boolean`_ - 是否禁用选择器。
- **loading** _`boolean`_ - 是否显示加载状态。

#### 特性

- 基于 Ant Design Select 组件，继承所有 Select 属性
- 标准化的选项数据格式 `{name, code}`
- 支持级联选择场景，常用于项目->期数->批次等有依赖关系的选择
- 完全兼容 Form 表单组件
