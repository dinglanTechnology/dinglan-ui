# OssFileUpload

OSS文件上传组件，基于 Ant Design Upload 组件封装，专门用于阿里云OSS文件上传。支持多文件上传、自定义文件名、进度显示、重试机制、图片预览、初始值显示等功能，完美集成Ant Design Form。

<Canvas of={OssFileUpload.Primary} />

## Usage

```ts
import { OssFileUpload } from "dinglan-ui";
import { Form, Button } from "antd";

const Example = () => {
  const [form] = Form.useForm();

  // OSS配置获取函数
  const generateOss = async () => {
    return {
      params: {
        expire: "1758678719",
        policy: "eyJleHBpcmF0aW9uIjoi...",
        signature: "EZdtdojCQWI5/Ex+l8HnQezGrBg=",
        accessid: "LTAI5tMCpHgpcdTpEMUXaoZQ",
        host: "https://assets-resource-1.oss-cn-chengdu.aliyuncs.com",
        bucket: "assets-resource-1",
      },
    };
  };

  const onSubmit = async () => {
    const values = await form.getFieldsValue();
    console.log("表单数据:", values);
  };

  return (
    <Form 
      form={form}
      layout="vertical"
      initialValues={{
        imageUpload: [
          "https://assets-resource-1.oss-cn-chengdu.aliyuncs.com/assets/images/example.jpg"
        ]
      }}
    >
      <Form.Item label="图片上传" name="imageUpload">
        <OssFileUpload
          filePath="assets/images/"
          generateOss={generateOss}
          listType="picture-card"
          maxCount={3}
          fileTypes={["image/*"]}
          fileName={["custom-1", "custom-2", "custom-3"]}
          maxFileSize={5}
          retryCount={2}
          onProgress={(percent, file) => {
            console.log(`${file.name} 上传进度: ${percent}%`);
          }}
          onSuccess={(url, file) => {
            console.log(`${file.name} 上传成功:`, url);
          }}
          onError={(error, file) => {
            console.error(`${file.name} 上传失败:`, error.message);
          }}
        />
      </Form.Item>
      
      <Button type="primary" onClick={onSubmit}>
        提交
      </Button>
    </Form>
  );
};
```

## API

### 必需参数

- **filePath** _`string`_ - OSS存储路径，文件将上传到此路径下
- **generateOss** _`() => Promise<OSSResponse>`_ - 获取OSS配置的异步函数

### 可选参数

- **value** _`string[]`_ - 组件值，用于Form集成和显示初始值
- **fileName** _`string[]`_ - 自定义文件名数组，按上传顺序使用
- **fileTypes** _`string[]`_ - 支持的文件格式，默认 `["image/*"]`
- **maxFileSize** _`number`_ - 文件大小限制，单位MB，默认5MB
- **retryCount** _`number`_ - 上传失败重试次数，默认0（不重试）
- **progress** _`UploadProps["progress"]`_ - 自定义进度条样式
- **onChange** _`(fileList: string[]) => void`_ - 文件列表变化回调
- **onProgress** _`(percent: number, file: File) => void`_ - 上传进度回调
- **onSuccess** _`(url: string, file: File) => void`_ - 上传成功回调
- **onError** _`(error: Error, file: File) => void`_ - 上传失败回调
- **children** _`React.ReactNode`_ - 自定义上传按钮内容
- **...restProps** - 继承 Ant Design Upload 的所有其他属性

### OSSResponse 接口

```typescript
interface OSSResponse {
  params: {
    expire: string;      // 过期时间
    policy: string;      // 策略
    signature: string;   // 签名
    accessid: string;    // 访问ID
    host: string;        // OSS域名
    bucket: string;      // 存储桶名称
  };
}
```

## 高级功能

### 文件名自定义规则

1. **按顺序命名**：文件按上传顺序使用fileName数组中的名称
2. **扩展名处理**：自动添加原文件扩展名（如果自定义名称没有）
3. **数组越界**：超出数组长度的文件使用原文件名
4. **完整扩展名**：如果自定义名称包含扩展名，直接使用

```typescript
// 示例
fileName={["custom-1", "custom-2.jpg", "custom-3"]}

// 结果（假设上传3个jpg文件）
// 第1个文件：custom-1.jpg（自动添加扩展名）
// 第2个文件：custom-2.jpg（保持完整名称）
// 第3个文件：custom-3.jpg（自动添加扩展名）
```

### 重试机制

- **网络错误重试**：网络异常时自动重试
- **OSS错误重试**：签名错误、权限错误等自动重试
- **重试日志**：控制台显示重试进度
- **最终失败**：重试次数用完后从列表移除文件

### 预览功能

- **图片预览**：jpg、png、gif、webp、svg等格式支持预览
- **文件下载**：非图片文件点击直接下载
- **缩放旋转**：预览时支持缩放、旋转等操作

## 注意事项

### OSS配置
- 确保 `generateOss` 函数返回正确的OSS配置
- OSS策略需要包含上传权限
- 建议设置合适的过期时间

### 文件格式
- `fileTypes` 支持MIME类型和通配符
- 使用 `["*"]` 表示支持所有格式
- 建议根据业务需求限制文件格式

### 性能优化
- 大文件上传建议设置合适的重试次数
- 多文件上传时注意并发数量
- 可通过 `maxCount` 限制同时上传的文件数量
- 组件内部已优化防闪烁机制，避免不必要的重渲染

### 错误处理
- 监听 `onError` 回调处理上传失败
- 检查网络连接和OSS配置
- 注意文件大小和格式限制
