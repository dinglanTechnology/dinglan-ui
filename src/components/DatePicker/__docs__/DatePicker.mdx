# DatePicker

DatePicker component with different props.

#### Example

<Canvas of={DatePicker.Primary} />

## Usage

```ts
import {DatePicker} from "sld-ui";

const Example = () => {

  return (
      <DatePicker />
  );
};

export default Example;
```

#### Arguments

- **pickerType** _`string`_ - 组件类型 date | dateRange | time | timeRange
- **valueRange** _`string`_ - 提交给接口是否为所选日期范围 true是，仅date、time
- **其他参数** _`any`_ -看antd文档
- **from 25.7.15**
